猛獣家族の川渡り

川渡り舟

父、母、息子ふたり、娘ふたり、召使い、そして犬。
この八人を、二人しか乗れない舟で対岸へ渡してください。
ただし——誰と誰を残すかを、間違えてはいけません。

ルール

  1. RULE 01

    父は、母がいないと娘を殺す。母のいない岸に、父と娘（どちらか一方でも）を残してはいけません。

  2. RULE 02

    母は、父がいないと息子を殺す。父のいない岸に、母と息子（どちらか一方でも）を残してはいけません。

  3. RULE 03

    犬は、召使いがいないと家族全員を殺す。召使いのいない岸に、犬と家族の誰かを残してはいけません。犬と召使いだけなら安全です。

  4. RULE 04

    舟は定員2名。漕げるのは父・母・召使いの3人だけ。行きも帰りも、必ずこの誰かが乗っている必要があります。

遊び方

  1. 「はじめる」を押す。押した瞬間からタイムの計測が始まります。それまで人物は動かせません。

  2. 人物をタップして舟に乗せる。舟のある側の岸にいる人だけが乗れます。もう一度タップすると降ります。定員は2名です。

  3. 「渡る」で対岸へ。枠が朱色の人物（父・母・召使い）が乗っていないと舟は出せません。舟に乗り込んだ人はもう岸にいない扱いになり、渡った瞬間に両岸の安全が判定されます。

  4. ルールを破ると「事件」。その場で「1手戻す」か「最初から」を選べます。事件が起きてもタイマーは止まりません。気軽に試して構いません。

  5. 八人全員が対岸に渡ればクリア。手数とタイムが表示されます。最少手数と最速タイムはそれぞれ別に記録されるので、じっくり最短を狙うのも、速さを競うのも自由です。

このパズルについて

「猛獣家族の川渡り」と呼ばれる、古典的な川渡りパズルのひとつです。 オオカミとヤギとキャベツを運ぶ有名な問題や、「宣教師と人食い人」の名で知られる問題と同じ系譜にあります。

違うのは規模です。渡すものが3つではなく八人あり、しかも舟を漕げるのは父・母・召使いの3人だけ。 誰かを対岸に送るたびに「今この岸に残るのは誰か」「向こう岸に増えるのは誰か」を同時に考えなければならず、それが一気に難しくしています。

最短は17手

このパズルは17回の渡河で解けます。そしてこれが理論上の最短です。 8人がどちらの岸にいるか（2の8乗＝256通り）と舟の位置の組み合わせ、あわせて512の状態をすべて幅優先探索で調べた結果なので、 16手以下の解は存在しません。

初めて解くと、たいてい25手から40手ほどかかります。17手に届いたなら、それはもう縮めようがない最善手順です。

よくある質問

川渡りパズルは何手でクリアできますか？

最短17回の渡河でクリアできます。全512状態を幅優先探索で調べた結果で、16手以下の解は存在しません。

舟を漕げるのは誰ですか？

父・母・召使いの3人だけです。行きも帰りも必ずこの誰かが乗っている必要があり、子どもと犬だけでは舟を出せません。

犬と召使いを2人きりにしても大丈夫ですか？

大丈夫です。犬が襲うのは家族6人で、召使いは家族に含まれません。犬が単独でいる場合も安全です。

舟に乗り込んだ人は岸にいる扱いになりますか？

なりません。舟に乗った時点でその人は岸を離れた扱いになり、「渡る」を押した瞬間に両岸の安全が判定されます。

スマートフォンでも遊べますか？

遊べます。インストールや会員登録は不要で、ブラウザだけで動きます。人物をタップして舟に乗せ、「渡る」を押すだけです。
